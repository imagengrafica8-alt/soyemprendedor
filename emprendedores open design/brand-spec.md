# Especificación visual — Soy emprendedor UVP

Fuente: `03-design-system.md`.

```css
:root {
  --bg: oklch(0.9816 0.0017 247.8);
  --surface: oklch(1 0 89.9);
  --fg: oklch(0.2178 0 89.9);
  --muted: oklch(0.4800 0.0180 257.1);
  --border: oklch(0.9288 0.0126 255.5);
  --accent: oklch(0.6681 0.1935 40.0);
  --font-display: "Parkinsans", sans-serif;
  --font-body: "IBM Plex Sans Hebrew", sans-serif;
  --font-mono: "SFMono-Regular", Consolas, monospace;
}
```

- El azul marino UVP estructura cabeceras, pies de página y títulos.
- El naranja UVP se reserva para acciones primarias, urgencia y estados activos.
- Las superficies claras, las rejillas modulares y el espacio en blanco reducen la carga cognitiva.
- Los títulos, encabezados e interfaz utilizan Parkinsans; la narrativa y las descripciones utilizan IBM Plex Sans Hebrew.
- La navegación es sticky y los controles mantienen foco visible y contraste WCAG AA.
